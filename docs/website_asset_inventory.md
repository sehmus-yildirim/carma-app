## Ergebnis

  **FUER NEUDESIGN PRUEFEN**

wird erneut nach HTML-, CSS-, JavaScript-, E-Mail- und Dokumentationsverweisen
gesucht.

einem Verweis auf den Dateinamen. Der SHA-256-Wert ist zur kompakten
Integritaetspruefung auf 16 Zeichen gekuerzt.

## Loeschregel fuer spaeter

Eine als `NACH NEUDESIGN ENTFERNEN` markierte Datei darf erst geloescht werden,
wenn:

1. das neue Design final implementiert ist,
2. Repository und Hosting-Quellen keinen Verweis mehr enthalten,
3. die Datei nicht fuer Store-, Auth-, E-Mail- oder Rechtsdokumentation benoetigt
   wird,
4. der resultierende Hosting-Diff separat geprueft wurde.
